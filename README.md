# Mi Página Web

Este proyecto es una landing page personal para Oswaldo Gil Valentín, con secciones de perfil, formación, pasatiempos y criptografía.

## Ejecutar localmente

Desde la carpeta del proyecto:

```bash
python -m http.server 8000
```

Luego abre en tu navegador:

```text
http://localhost:8000
```

## Archivos principales

- `index.html` — contenido principal de la página
- `CV_Oswaldo_Gil.pdf` — CV descargable (si existe en la carpeta)
- `public_key.asc` — clave pública PGP (si existe en la carpeta)
